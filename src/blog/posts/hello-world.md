So... I managed to make my own website this time. It's a simple thing but it's rather something that I would actually realistically made if I were to make a blog and somewhat of a portfolio where the only content that really matters is the text. Hence this rather... simplistic and perhaps even old-fashioned style of a layout is something that would be unexpected to see in a sea full of hyper-animated portfolios and blogs running on WordPress.

But I'm not manually making these pages. Oh no no, that would be such a pain in the arse to do. I do use [11ty](https://www.11ty.dev/) for this and it's a rather nifty tool for creating websites from scratch. Although I had to do some more manual setup since it's pretty much a bare bones SSG with no batteries included. I could've used a starter project but unironically I found myself too lazy to find a good one so it's best to just do a manual setup. But overall, I found it good enough to work with, at least for now. Who knows if I'll regret this decisions later haha!

## Why not use WordPress?

WordPress feels like I need to manage a lot of things. Sure I can just apply a theme and then just keep on writing posts but I just think I don't need any of WordPress' features. I just want to write Markdown, push, build the static site, and then serve it. It's a lot more hoops then just writing a post in a WordPress site but I guess this is just more personalized and I think that's fine.

## How about other static site generators (e.g. Hugo, Jekyll)?

I actually tried out Hugo before and it was actually the first iteration of this blog. But I sort of forgot about it and I wanted something far more simpler for this webspace. I have heard of Jekyll before but I'm not really going to get into the Ruby ecosystem for this. I also think it's a bit old too? I saw Jekyll way back then during the 2010s. Their site is even old school to this day (just like mine!)

## So how did you set up 11ty?

So I've had it set up to use TypeScript because no sane developer should use regular JavaScript unless they're even more of a masochist than I am. I don't plan on adding some scripting here. Maybe analytics if I really want to see if people actually visit my website, although I might actually see more LLM traffic than actual real traffic.

Anyways, posts are in Markdown just so I can simply just write things instead of trying to think about HTML even in a blog post. If I really want to just use HTML for writing posts then I should've not tried to use a static site generator at all!

Other than that, I just set up a few layouts written in Nunjucks because it's closer to HTML than any of the other ones out there. I then spend hours trying to do CSS (I'm not a particularly good web designer), and then spend the remaining time writing this post while also adjusting some things along the way.

## So what should I expect here?

Expect a lot of rambling, hahaha! I think this is just something that I would dump a whole lot of my thoughts are, mostly in how I make some stuff. It's also a portfolio website so I might preview some of the work that I do, including projects that are somewhat prettier than this personal webspace simply because I use a component library to do the styling job for me.

Overall, it's a massive text dump and a simple showcase of my projects. It's not particularly going to be a very flashy website since I prefer to build backend systems more than I want to build frontend systems. So I think a minimalist front suits my needs, at least for the time being. But I might make it a bit more prettier, but for now, it shall stay very simple.
